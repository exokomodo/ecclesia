# 2026-03-30 — Ecclesia OS Day

## Summary
Spent the full day with James building **Ecclesia** — a Common Lisp microkernel OS targeting x86-64 bare metal. Enormous amount of ground covered.

## Project: Ecclesia

- **Repo:** https://github.com/exokomodo/ecclesia
- **Concept:** Modern Lisp Machine — microkernel OS written entirely in Common Lisp + minimal assembly. Inspired by yalo (https://github.com/whily/yalo).
- **Name origin:** James suggested naming it after Church (Alonzo Church, lambda calculus). "Ecclesia" = Latin for "church/assembly."

### Boot chain achieved (fully working in QEMU):
1. Stage 1 MBR (16-bit real mode) → prints "Ecclesia booting...", loads Stage 2
2. Stage 2 → 32-bit protected mode → 64-bit long mode (with verbose [OK] status lines)
3. Kernel at 0x100000 → keyboard polling loop (PR #18, not yet merged)

### Key technical milestones:
- Wrote a **two-pass x86-64 assembler entirely in Common Lisp** (definsn registration table, forward label resolution)
- Implemented GDT, page tables (16MB identity-mapped), PAE, EFER.LME, paging
- VGA text buffer writes working from both 32-bit PM and 64-bit LM
- PS/2 keyboard polling with scancode→ASCII lookup table
- Floppy image padded to 1.44MB so INT 13h geometry works in QEMU

### Major bugs caught and fixed:
- `LGDT` size was 4 bytes, should be 5 → corrupted GDT, far jump landed in BIOS ROM
- `RDMSR`/`WRMSR` size was 1 byte, should be 2 → off-by-2 label offsets
- `eval-expr` only handled 2-arg expressions → `(- gdt-end gdt-start 1)` dropped the `-1`
- Floppy image was too small → INT 13h rejected reads entirely
- `src/build/` was in `.gitignore` (matched `build/` pattern) → files never tracked
- `(org N)` form used package-local symbol → origin defaulted to 0 for cross-package instruction lists
- `canonicalize-form` needed to apply to all operands, not just mnemonics

### Architecture (final layout):
```
src/
  package.lisp          — ecclesia.build + ecclesia packages
  build/
    assembler/
      assembler.lisp    — generic two-pass core
      x86-64.lisp       — x86-64 instruction encodings
      README.md
    utils/
      vga-print.lisp    — vga-write, vga-status, vga-rdi-write, vga-rdi-status
    boot/
      bootloader-x86-64.lisp
      stage2-x86-64.lisp
  kernel64/
    main.lisp           — 64-bit kernel entry point
```

### Package split:
- `ecclesia.build` — build toolchain (assembler, VGA helpers, boot code)
- `ecclesia` — kernel runtime (`:use ecclesia.build`)
- Mnemonics canonicalized to `ecclesia.build` package at lookup time — instruction forms work from any package
