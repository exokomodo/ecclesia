### `icon_font_generator` API hell (v3 → v4)
- v3 used named flags `--from`, `--out-font` → broken with error `Could not find bin/generate.dart`
- v4 (4.1.0) doesn't expose a CLI binary at all — `flutter pub run icon_font_generator:generate` fails with `Could not find bin/generate.dart`
- Correct approach: use the Dart API directly via `tool/generate.dart`

### Actual v4 API (from pub cache `icon_font_generator-4.1.0/lib/src/common/api.dart`)
- `svgToOtf({required Map<String, String> svgMap, bool normalize, String fontName})` → returns `SvgToOtfResult`
- `result.font.encode()` → `List<int>` bytes for the OTF file
- `generateFlutterClass({...})` → takes `glyphList`, NOT `svgDir`
- Output is `.otf` not `.ttf`

### Key design decision
`lib/autobutler_icons.dart` is HAND-AUTHORED — contains Material icon aliases + custom SVG codepoints. Generator script should only write the font binary, NOT overwrite the dart class. The `tool/generate.dart` script was updated to only produce `fonts/AutobutlerIcons.otf`.
