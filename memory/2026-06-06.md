### Key technical facts
- Flutter version in CI: `stable-3.41.9-x64`
- flutter_quill version: `11.5.0` — `readOnly` is on `QuillController`, NOT `QuillEditorConfig`
- `dart format` can escape `${...}` to `\${...}` in certain string contexts — always verify template strings after formatting
- `dart:typed_data` is re-exported by `flutter/services.dart`; explicit import causes `unnecessary_import` lint error
- Makefile lint target: `make check/format/flutter` and `make check/lint/flutter`
- Theme persistence: `AppSettings.instance.setThemeMode()` / `AppSettings.instance.themeMode` (ValueListenable<ThemeMode>)

### Lessons learned
- Always run `dart format` before committing Flutter code (CI checks it)
- When subagents commit Flutter code, verify they ran `dart format`
- Check flutter_quill changelogs when API issues arise — v11 had breaking changes
- `ThemeToggleButton` is now a reusable widget at `lib/widgets/layout/theme_toggle_button.dart`
